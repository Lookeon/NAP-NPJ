## Sobre cada portal

### NAP
Espaço institucional de escuta, orientação e acompanhamento psicopedagógico para a comunidade acadêmica. O site apresenta:

- Sobre o núcleo e sua finalidade
- Atividades (acolhimento, rotina de estudos, habilidades acadêmicas, acessibilidade curricular e encaminhamentos)
- Projetos relacionados (NAP Itinerante, Rodas de Conversa, Embaixadores do NAP, entre outros)
- Como funciona o atendimento e informações de contato

Visual em tons de verde.

### NPJ
Espaço acadêmico do curso de Direito que oferece assistência jurídica gratuita, com atendimento feito por alunos supervisionados por professores. O site apresenta:

- Sobre o núcleo e suas atividades
- Áreas de atuação (Civil, Família, Trabalhista, Consumidor, Previdenciário e outros)
- Serviços oferecidos
- Como solicitar atendimento e informações de contato

Visual em tons de azul.

## Tecnologias

- HTML5
- CSS3 (Flexbox, Grid e media queries para responsividade)
- [Lucide Icons](https://lucide.dev/) para os ícones
- [Google Fonts](https://fonts.google.com/) (Inter)

## Como visualizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Lookeon/NAP-NPJ.git
   ```
2. Abra o arquivo `index.html` da pasta `NAP` ou `NPJ` no navegador.

Também é possível usar a extensão **Live Server** do VS Code.

> É necessário estar conectado à internet para carregar os ícones, a fonte e algumas imagens.
